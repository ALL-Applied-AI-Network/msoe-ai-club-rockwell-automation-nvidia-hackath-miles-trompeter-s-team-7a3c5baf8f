Standard Operating Procedure

Fill Line Image Capture

For: new operators Applies to: Vial Fill · Tank Level · Cap/Seal cameras Rev. 2026-09-22
1. Vial Fill 2. Tank Level 3. Cap/Seal

Before you start

Check these off as you confirm them.
0 / 3
1

Start the program

  • Double-click start_capture.sh in the project folder.
  • Wait about 10 seconds. A window opens with three live video panels: Vial Fill (left), Tank Level (middle), Cap/Seal (right).
If a panel says "No camera detected" instead of showing video, click Reconnect Camera in that panel. Still nothing? Get a supervisor - don't unplug or replug the cameras yourself.
2

Leave the Batch ID as-is

At the top of the window, Batch ID is already filled in for you, like 2026-09-0003. It's generated automatically for this work session - leave it alone unless a supervisor tells you otherwise.

3

Start Vial Fill + Tank Level capture

Below the top bar is a Synchronized Capture control for the Vial Fill and Tank Level cameras. Set the rate (seconds between shots) if it isn't already right, then click ● Start. From then on, both cameras save a picture together, automatically, at that rate - you don't touch them again until the end of the shift.

Do this once at the start of the shift or batch, not per vial. Leave it running the whole time.
4

Set the Order / Run # for this vial

Order / Run #, next to Batch ID, tags which vial the Cap/Seal photo below belongs to. Make sure it matches the vial currently reaching the Cap/Seal station - start at 1 for a brand-new batch.

5

Capture this vial at Cap/Seal

Once this vial is capped and sealed, click Capture on the Cap/Seal panel, check the frozen picture looks good, then click Save - or Retake if it's blurry or cut off.

Vial Fill and Tank Level don't have Capture/Save buttons anymore - they're already running from Step 3.
6

Move to the next vial

Once Cap/Seal's photo for this vial is saved, click Next Order ▸ one time. Then repeat Steps 4-6 for the next vial.

7

End of shift or batch

Click Stop on the Synchronized Capture bar (and on the Video Capture bar too, if a supervisor had you start it) then click Exit in the bottom-right corner. All three cameras are released automatically - it's always safe to close the window this way.

Optional: recording video

There's a separate Video Capture bar (below Synchronized Capture) that records plain continuous video from all three cameras at once - not part of the normal per-vial routine above. Only use it if a supervisor asks you to: click ● Start Recording at the start of the period they want recorded, Stop Recording at the end. It runs fine alongside everything in Steps 3-6.

If something looks wrong

You seeDo this
A panel says "No camera detected"Click Reconnect Camera in that panel.
Video is frozen or blackClick Exit, then start the program again.
Synchronized Capture stopped by itselfOne of the two cameras lost connection - check that panel, click Reconnect Camera if needed, then click Start again.
The wrong station's video is in the wrong panelDon't try to fix it yourself - tell a supervisor.
Not sure what Order / Run # to useAsk a supervisor. Don't guess.

Do

  • Start Synchronized Capture once, at the start of the shift, and leave it running.
  • Capture at Cap/Seal right when each vial is capped and sealed.
  • Use Retake if a Cap/Seal picture is blurry, dark, or cut off.
  • Click Next Order only after Cap/Seal's photo for that vial is saved.

Don't

  • Unplug or replug a camera while the program is running.
  • Change any settings you weren't shown in training.
  • Run a second copy of the program at the same time.
  • Stop and restart Synchronized Capture mid-shift unless a camera dropped.
